BLT-CVE
Vulnerability Registry

A standards-driven, machine-readable, cryptographically verifiable, federated vulnerability registry running entirely on GitHub Pages and GitHub Actions — no backend required.

Submit a Vulnerability View on GitHub

Disclaimer

BLT IDs are not MITRE-issued CVE IDs. They are community-assigned identifiers within the OWASP BLT ecosystem. Always cross-reference with official CVE sources for production security decisions.

Endpoints (Machine-Readable)

Direct access to registry data in standard JSON formats.

Endpoint Description Link
/index.json Lightweight master index — ID, path, severity Open
/feed.json Full metadata feed — titles, dates, severity Open
/federation.json Federation manifest for mirrors and aggregators Open
/schema/blt-cve-schema.json JSON Schema (Draft-07) for entry validation Open
/cves/YYYY/BLT-YYYY-NNNN.json Individual vulnerability entry Example

Schema

Required fields for every BLT-CVE entry.

  • id

    identifier (string)

    BLT-YYYY-NNNN identifier

  • dt

    published/modified (string)

    ISO-8601 date-time

  • ti

    title/description (string)

    Summary (10-200) and full technical description (≥20 chars)

  • af

    affected (array)

    One or more affected product objects

  • sv

    severity (object)

    CVSS score + vector string

Note: signature is optional — reserved for future cryptographic signing.
